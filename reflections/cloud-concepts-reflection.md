# Cloud Computing Reflection Paper

In today’s digital world, cloud computing plays a big role in how I use technology every day. Some of the most common cloud-based services I use are Google Drive, Netflix, and Facebook Messenger. These applications make my life easier because I can access files, communicate with others, and enjoy entertainment anytime and anywhere as long as I have an internet connection.

Google Drive is an example of Software as a Service (SaaS) and uses a public cloud deployment. I use it to store files, submit schoolwork, and share documents with classmates. It is considered SaaS because I don’t need to install or manage anything—it is all handled online. Netflix is also a SaaS application under the public cloud. It allows me to watch movies and shows without downloading them. Messenger is another SaaS platform that I use daily for communication. It is also part of the public cloud because it can be accessed by many users worldwide.

Learning about these cloud models helped me understand how these services work behind the scenes. I realized that companies manage the systems and infrastructure, while users simply use the services provided.

Git and GitHub are also important in cloud computing because they help manage changes in projects. Version control allows users to track updates, avoid errors, and return to previous versions if needed. GitHub also improves teamwork by allowing multiple users to collaborate, review changes, and organize tasks efficiently.

Overall, cloud computing is very useful in my daily life and studies. It makes technology more accessible and convenient, while GitHub helps ensure that projects are organized, accurate, and efficient.
