# Cloud Computing Reflection Paper

In today’s digital world, cloud computing plays a big role in how I use technology every day. Many of the applications I use daily rely on cloud services to store data, provide features, and allow access anytime through the internet.

Three cloud services I regularly use are Google Drive, GCash, and Facebook Messenger. Google Drive is a Software as a Service (SaaS) because it allows me to store, edit, and share files online without managing any hardware or software. It uses a Public Cloud deployment model since it is accessible to anyone with an internet connection. GCash is also a SaaS application because it provides online financial services such as sending money, paying bills, and managing transactions without requiring users to handle the system behind it. It is considered a Public Cloud service because it is available to many users through the internet. Facebook Messenger is another SaaS platform that allows real-time communication. Like the others, it operates on a Public Cloud because it serves many users over the internet.

Learning about these cloud models helped me better understand how these services work behind the scenes. I realized that companies are responsible for managing the infrastructure, while users only focus on using the service.

Git and GitHub are also important in cloud computing projects. Version control is critical because it tracks all changes made to files and helps prevent errors. If something goes wrong, it is easy to return to a previous version. GitHub also supports collaboration by allowing multiple users to work on the same project, review updates, and organize tasks efficiently. This helps teams avoid conflicts and manage cloud resources more effectively.

Overall, cloud computing makes technology more accessible and convenient in my daily life. At the same time, GitHub helps ensure that projects are organized, accurate, and easier to manage, especially when working with others.
